# jadebonifacio.dev

Personal portfolio. Next.js 15 (App Router), TypeScript, Tailwind v4, pnpm.

- `DESIGN.md` is the source of truth for every visual decision.
- `content/` holds the case studies as markdown.
- `design-reference/` (git-ignored) holds imported Claude Design files.

```sh
pnpm install
pnpm dev
```
